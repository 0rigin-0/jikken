LINUX BASICS

なぜLinuxを学ぶの？

コンピュータの中身を、
自分の目で見る。

サーバーの多くはLinuxで動いていて、セキュリティの基本ツールや仕組みもLinuxを前提に作られています。Linuxの操作を覚えると、ファイルやプロセス、ネットワークがどう動いているかを理解しやすくなります。

最初は黒い画面に慣れなくても大丈夫。コマンドは、コンピュータへのお願いを短い言葉で伝える方法です。

コマンド早見表を見る →
learn_linux.sh
$ pwd /home/learner
$ ls clues notes tools
$ cat note.txt keep looking.
$ file image.png PNG image data

Linuxコマンド早見表

Linuxコマンド
早見表

コマンドは実際に入力して試すと身につきます。分からないときは `man コマンド名` で説明書を開けます。

STEP 01

まずはこの3つだけでOK

ファイルを見る・場所を移動する・中身を読む。最初はこの3つから始めます。

lsファイルとディレクトリを一覧表示
cd <dir>作業する場所を変更
cat <file>ファイルの中身を表示
STEP 02

CTFでよく使う

手がかりを探したり、ファイルの正体を確かめたりします。

grepファイルの中から文字を検索
find条件に合うファイルを探す
fileファイルの種類を判別
strings読める文字列を取り出す
STEP 03

慣れてきたら

ネットワークや権限を扱うときに少しずつ覚えます。

ssh許可されたサーバーへ接続
nc許可されたホストと通信を確認
wgetURLからファイルを取得
chmodファイルの権限を変更

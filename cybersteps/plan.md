# 「見て、知って、解いてみる。」実装計画

## 1. ゴール

サイバーセキュリティ未経験者が、**「難しそう」から「まず1問解いてみよう」へ進み、実際に正解体験を得る**ための静的教育サイトを構築する。

主な対象は高校生、専門学校生、大学生、IT初心者、CTF未経験者。専門用語を前提にせず、**見る → 知る → 解く → もっと挑戦する**という一本の体験導線を最優先にする。

バックエンド・ログイン・会員登録・個人情報・データベース・利用者追跡は実装しない。全機能は HTML / CSS / JavaScript を中心とした静的構成で実現し、CTF の正誤判定もブラウザ側だけで行う。

---

## 2. サイトマップとページ構成

| 画面 | URL / 表示 | 主な役割 | 次の行動 |
|---|---|---|---|
| ホーム | `/` | サービスの安心感と「最初の1問」への興味をつくる | 「まずは1問解いてみる」 |
| はじめてのCTF | `#ctf` または専用表示 | CTF を「謎解き × サイバーセキュリティ」として直感的に紹介する | 最初の問題へ |
| 学習 | `#learn` とカテゴリ切替 | Security Basics、Network、Linux、Web、Crypto、Forensics、OSINT、Reverse Engineering、Pwnの学習ロードマップと初学者向け解説を示す | 確認問題／CTFに挑戦 |
| チャレンジ | `#challenge` と問題詳細モーダルまたは専用表示 | 3問の安全な疑似CTF問題を出題し、ヒント・解答・解説を提供する | 次の問題へ |
| 防衛省・自衛隊 | `#defense` | サイバー分野での取り組みを、勧誘ではなく事実ベースで紹介する | 公式情報を確認する |
| About / 外部リンク | フッター・セクション | サイトの意図、ゲーム連携、次の学習先と外部リンクを示す | 学習・イベントへの遷移 |

初期版は静的シングルページを採用し、ナビゲーション・CTA・アンカーリンク・問題表示を滑らかに接続する。これにより初学者が画面遷移で迷わず、GitHub Pages / Cloudflare Pages / Vercelにそのまま載せられる構成にする。

## 3. 体験設計・ユーザーフロー

1. ヒーローで「見て、知って、解いてみる。」と、初心者に向けた姿勢を伝える。
2. 「専門知識が必要？」「プログラミングできないと無理？」「CTFって何？」という不安をカードで代弁し、「大丈夫。まずは簡単な問題から。」で心理的負担を下げる。
3. 「知る・解く・挑戦する」の3ステップを、1本のガイドラインでつなげる。
4. CTFを「謎解き × サイバーセキュリティ」と短く紹介し、問題への抵抗を下げる。
5. 初心者問題カードから最初の問題を開く。問題画面では、説明 → ヒント → Flag入力 → 判定の順で迷わせない。
6. 正解時は控えめなチェック演出、`CORRECT!`、初心者向け解説、次の問題への明確なボタンを示す。
7. 問題後はロードマップ・カテゴリ学習・外部のコンテスト／CTFへ自然に広げる。

ゲーム側からは、Forensics / Network / Crypto / OSINT / Webなどのカテゴリリンクを使って該当する学習表示へ直接到達できる設計にする。

## 4. デザイン方針

### デザインムーブメント

**コンテンポラリー・インスティテューショナル × 探究ノート**。公共性・信頼性を感じる編集的なレイアウトに、初心者の発見を助ける小さな「ミッション」表現を重ねる。

### コア原則

- **親しみやすい防御感**：攻撃や脅威を強調せず、知識で守る印象をつくる。
- **段階の可視化**：どの位置にいて、次に何をすればよいかを常に示す。
- **短い情報単位**：見出し、短い説明、カード、CTAという順で理解させる。
- **落ち着いた達成感**：正解時にも過剰な演出を使わず、小さな成功を丁寧に祝う。

### カラー哲学

背景にはオフホワイトと濃いインク色を用いて可読性・信頼感を確保する。深いダークグリーンは防御・専門性、セージグリーンは初学者へのやわらかさ、ゴールドは進捗・発見・正解のアクセントとして限定的に使う。赤やネオングリーンに頼らず、「怖いサイバー」ではなく「知的に学べるサイバー」を表現する。

| 用途 | 色 | 役割 |
|---|---:|---|
| Deep Defense | `#143B35` | ブランドの主軸、主要CTA、見出し |
| Sage Field | `#AFC3AE` | 安心感のある面・タグ・補助情報 |
| Paper | `#F5F3EA` | メイン背景、余白、読みやすさ |
| Ink | `#15211F` | 本文とコントラスト |
| Signal Gold | `#C99B45` | 進捗、難易度、正解・発見のアクセント |

### レイアウト

一般的な均一グリッドではなく、**左端のステップ番号・縦のガイドライン・少しずらしたカード群**で、学びが前へ進む感覚を作る。ヒーローは大きなタイポグラフィと、右側の抽象的な「防御レイヤー」図形で構成する。画像を増やさず、CSSの線・輪郭・ソフトな面・アイコンで世界観を統一する。

### シグネチャ要素

- `01 / 02 / 03` の大きな章番号と縦の進行ライン
- 盾・チェック・鍵穴・ノードを抽象化した線画アイコン
- Goldの小さな「MISSION」タグ、進捗ドット、難易度スター

### インタラクションとアニメーション

- CTAは軽い浮き上がりと色の変化で押せることを明確にする。
- スクロール時は各セクションを短いフェード＋上方向移動で表示する。
- カードはホバー時のみわずかに持ち上げる。
- ヒントは段階的に展開し、いきなり答えを示さない。
- 正解時はチェックマークと淡いGoldのリングを一度だけ表示する。
- `prefers-reduced-motion` を尊重し、動きを減らせるようにする。

### タイポグラフィ・声の設計

日本語は可読性の高い `Noto Sans JP`、英数字・ステップ番号は幾何学的な `DM Mono` / `Space Grotesk` 系を使い分ける。大見出しは短く力強く、本文は一文を短く保つ。

- ブランドエッセンス：**はじめての好奇心を、守る力につなげるCTF入門。**
- 性格：**知的、穏やか、励ます**
- 文体例：「答えを知るより、自分で見つけるほうが面白い。」「まずは、いちばんやさしい1問から。」
- ロゴ案：角丸の盾の中に、進行方向を示す小さな3つの点とチェックを組み合わせたマーク。ワードマークは装飾よりも読みやすさを優先する。
- 固有のブランドカラー：**Deep Defense Green `#143B35`**。

## 5. 実装するコンテンツと機能

### ホーム

- スクロール追従ヘッダー：ロゴ、HOME、はじめてのCTF、LEARN、CHALLENGE、ABOUT、防衛省・自衛隊、`CHALLENGE NOW →`。
- モバイル用のハンバーガーメニュー。
- ヒーロー、初心者の不安カード、3 STEP、CTF紹介、問題カード3枚、ロードマップ、ゲーム連携、挑戦者向け外部リンク導線、防衛省・自衛隊紹介、フッター。
- 初心者問題：
  1. Base64を解読せよ（Crypto／★☆☆☆☆）
  2. 隠されたファイルを探せ（Forensics／★☆☆☆☆）
  3. 怪しい通信を見つけろ（Network／★★☆☆☆）

### 学習表示

各カテゴリに以下の共通順序を設定する。

1. これは何？
2. なぜ重要？
3. 初心者向け解説
4. 具体例
5. 確認問題
6. CTF問題

専門用語は「簡単な説明 → 正式名称」の順で紹介する。初期実装では、ロードマップ全カテゴリの入口と、問題に対応するCrypto / Forensics / Networkの詳細を特に充実させる。

### CTF問題体験

- 問題番号、タイトル、カテゴリ、難易度、問題文、ヒント、Flag入力、判定ボタンを表示する。
- FlagはJavaScriptで大文字小文字を含めて判定する。
- 不正解時は `INCORRECT` と「もう一度考えてみよう。」を表示する。
- 正解時は `CORRECT!`、チェックマーク、軽いアニメーション、解説、使用した知識、覚えてほしいポイント、次の問題ボタンを表示する。
- ヒントは最初は閉じ、クリック時に思考を助ける情報だけを開示する。
- 実在システムへの攻撃、意図的な脆弱性、危険な操作は一切含めない。

### 防衛省・自衛隊／外部リンク

- 防衛省・自衛隊のサイバー分野は、採用・勧誘としてではなく「どのような役割や取り組みがあるか」を説明する読み物として作成する。
- 事実に関わる記述は実装時に防衛省・自衛隊の公式情報で確認し、意見・編集上の説明と混同しない。
- 「もっと挑戦したい人へ」で、防衛省のサイバーコンテスト、CTF、関連イベントへの外部リンクを追加できるカード構造を用意する。

## 6. コンポーネントとデータ構造

### 共通UI

| コンポーネント | 役割 |
|---|---|
| Header / MobileMenu | セクション移動と最初の問題へのCTA |
| Footer | サイト概要、学習、CTF、防衛省・自衛隊、外部リンク、著作権 |
| Button | 主・副・テキスト型CTA |
| SectionHeading | 章番号、ラベル、見出し、短い説明 |
| InfoCard / StepCard | 不安の代弁と3ステップの説明 |
| ChallengeCard | カテゴリ・難易度・挑戦導線を持つ問題カード |
| DifficultyBadge | 星と初心者／初級などの難易度表現 |
| RoadmapCard / ProgressBar | 学習段階とカテゴリへの導線 |
| HintBox / AnswerInput / ResultPanel | CTFの問題体験 |
| ChallengeModal | 問題、回答、解説、次の問題を1画面で扱う表示 |

### データ分離

問題は `data/challenges.js` の配列としてコード本体から分離する。各問題は以下の形を持ち、追加・変更しやすくする。

```js
{
  id: 1,
  title: "Base64を解読せよ",
  category: "Crypto",
  difficulty: 1,
  description: "...",
  hint: "...",
  answer: "FLAG{...}",
  explanation: "...",
  takeaway: "..."
}
```

学習ロードマップとカテゴリ説明も `data/learning.js` に分離し、ゲーム側のカテゴリ連携先を増やしやすくする。

Viteを最小の静的開発サーバーとビルド手段として使う。Reactなどのフレームワークは導入せず、依存を抑えたHTML / CSS / JavaScript構成とする。

## 8. アクセシビリティ・SEO・レスポンシブ方針

- `header`、`main`、`section`、`article`、`nav`、`footer`、適切な見出し階層を使う。
- ボタン、入力欄、モーダルをキーボード操作可能にし、フォーカスを明確に表示する。
- アイコンや装飾には適切な代替テキストまたはARIA属性を与える。
- スマートフォンではナビゲーションをハンバーガー化し、タップ領域・文字サイズ・入力欄を十分に確保する。横スクロールを発生させない。
- title、description、OGP、favicon、意味のある画像代替情報を用意する。
- 初期HTML自体に主要コンテンツを含め、JavaScriptなしでも意図と主要セクションが読めるようにする。
- 公開用の絶対URLが確定するまでは、推測したcanonical / OGP URLは出力しない。

## 9. 実装・公開の前提

- Manus Webdevの静的Webプロジェクト（`/home/ubuntu/cybersteps`）に実装する。
- サーバー・データベースは使用しない。
- 外部コンテスト等は、外部URLを安全に差し替えられる構造とする。防衛省・自衛隊に関する具体的事実とリンク先は実装時に公式情報を確認して設定する。
- 公開先は静的ホスティング対応のビルド成果物とし、まずManus Previewで動作確認する。公開URLは別途公開操作が行われた場合のみ確定する。

---

## 10. 確認方法

- モバイル・タブレット・デスクトップ幅で、文字、CTA、カード、問題入力、モバイルメニューに横スクロールや操作不能がないことを確認する。
- 3問それぞれで、ヒント表示、不正解表示、正解表示、解説表示、次の問題への遷移を確認する。
- `manus-routes.json` が静的に配信されること、主要メタ情報・favicon・見出し階層・代替テキストが揃うことを確認する。
- 問題データの追加箇所が `challenges.js` に集約されていること、外部リンク・防衛省の紹介が事実ベースの構造であることを確認する。
- ビルドとプレビュー起動を行い、ブラウザ上で主要CTAの導線を点検する。

## 11. サイトマップ再構成版（2026-10-03）

追加要件に合わせ、トップページを単一ページのまま、以下の4本柱へ再編成した。`#satcon` はサイコンの概要・参加条件・申し込み・環境・FAQ、`#ctf-know` はCTFの説明・歴史・カテゴリ・面白さ、`#beginner` はLinux入門・使用ツール・必要な知識、`#challenge` は例題・常設問題への入口を担当する。参加者像、セキュリティ職種、公式情報へのリンクも同一ページ内のアンカーとして接続する。

デザインは参考サイトの柔らかな余白、白〜淡いブルーの面、角丸カード、段階的な説明を取り入れつつ、既存の深いブルー・金色アクセント・盾のクリック回転を維持する。事実が更新される可能性のある大会条件は、最新の公式案内を確認するよう注記する。

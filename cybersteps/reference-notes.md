# 参考サイトのデザイン要点

参照URL: https://recruit-diversity.jreast.co.jp/

確認日: 2026-10-03

参考にする要素:
- 大きな見出しと短い導入文で、初見でも内容が分かる構成
- 白〜淡色の広い余白、淡いブルーの背景、深いブルーの文字
- 角丸のカードと控えめな境界線、柔らかな影
- いきなり専門情報を詰め込まず、段階的に内容を紹介する
- セクションごとに短い見出し、説明、カード、CTAを配置
- 人柄や参加者像、FAQ、環境、イベントなどを並べ、心理的ハードルを下げる

ユーザー添付資料の方向性:
- 深い青〜淡い青を基調に、金色を少量アクセントとして使う
- 盾をヒーローの象徴として大きく配置し、クリックで回転させる
- サイバーコンテスト、CTF紹介、カテゴリ紹介、初心者ガイド、問題集を明確に分ける
